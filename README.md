# 轮对镟修余量规划台（Wheelset Reprofiling Allowance Planner）

浏览器端的地铁轮对镟修前余量规划工具：导入四个车轮（M1/M2 一位轴、T1/T2 二位轴）的横向轮廓与
实测滚动圆直径，选择目标型面与公差，系统完成 **校验 → 基准刚体对齐 → 单轮最小切深 →
四轮耦合离散搜索**，在首屏联动展示轮廓叠图、尺寸标注、轮对布局与候选方案表；支持候选预览、
采用、撤销/重做，数据保存在本地浏览器（localStorage），刷新可恢复。

技术栈：**React 18 + TypeScript + Vite + Vitest**，纯前端、无后端、无网络请求。

## 快速开始

```bash
npm install
npm run dev        # 本地开发 http://localhost:5173
npm test           # 运行全部测试（vitest）
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览构建产物
```

顶部一键切换三个内置示例：**正常磨耗**、**偏磨/凹磨**（复杂交叉 + 噪声）、
**缺测无解**（T2 加工区间缺段）。

## 工作流与算法

### 1. 导入与校验（`src/lib/validate.ts`）

- 支持单轮 CSV（首行可写 `# M1,837.4`，其后 `x,y`）、单轮 JSON 与整车 JSON；可导出整车 JSON。
- 坐标系：规距面（轮缘背侧基准面）`x=-70`，名义滚动圆刻线 `x=0`，踏面外侧为正；
  `y` 相对滚动圆切线向上（轮缘顶方向）为正，单位 mm。
- 校验内容：有效点数、NaN、**点序方向**（自动识别踏面→轮缘反向并翻转，折返点序报警后重排）、
  重复 x 合并、规距面/加工区**覆盖**、点距超阈的**缺段**、抗差噪声 σ、孤立毛刺（基于局部
  邻域孤立性，避免把轮缘曲率误报为毛刺）。

### 2. 基准刚体对齐（`src/lib/align.ts`）

在踏面近直基准带（默认 x∈[28,38]，可改）内，对实测轮廓做**微转角 θ + 平移 (dx,dy)** 的
Huber 抗差 IRLS 拟合（加权 3×3 正规方程，单步限幅），把实测变换到目标坐标系。

- 逐 x 比较残差，**不使用最近点/ICP 硬凑**；局部磨耗、毛刺点被降权而非迁就。
- θ 超 10 mrad、基准带残差异常、基准带无点均显式上报。

### 3. 最小切深与轮缘尺寸（`src/lib/cut.ts`、`src/lib/metrics.ts`）

加工区间（默认 x∈[-40,35]）内，目标型面整体径向内移 `d` 后必须完全落在现存材料内：

```
对所有覆盖点 x:  T(x) − d ≤ M(x)   ⇒   dMin = max_x [ T(x) − M(x) ]
```

- 0.25 mm 固定 x 栅格逐点比较间隙 `g=T−M`；**缺段栅格不参与约束**（不插值凑数），
  报告缺段区间与覆盖率，此时 dMin 只是“已覆盖部分的下界”，结果标记 `unstable`/致命，
  搜索直接拒绝该方案。
- 同时计算中值平滑结果的 dMin，给出两者差值作为**不确定度**；间隙变号次数用于提示
  偏磨/凹磨形貌的交叉复杂性。
- 允许最大切深由最小轮径约束给出：`Dpost = D实测 − 2(d + tapingY) ≥ Dmin`。
- 轮缘尺寸全部由**水平切面与型线的真实交点**计算：
  - **Sh**：轮缘顶点相对实测滚动圆切线（x=0 处型线高度）的高差；
  - **Sd**：y=10 水平线与轮缘面交点到规距面 x=−70 的横向距离；
  - **qR**：y=2 与 y=9 两水平切面之间轮缘面的型线**弧长**（矩形窗口精确剪裁累计）。

### 4. 四轮耦合离散搜索（`src/lib/planner.ts`）

决策变量为各轮径向进刀 `d_i`（进刀步长的整数倍，只能去料 `d_i ≥ dMin_i`），约束：

- 最小轮径：`Dpost_i ≥ Dmin`；
- 同轴径差：`|D_M1−D_M2| ≤ 限值`、`|D_T1−D_T2| ≤ 限值`；
- 转向架径差：`max Dpost − min Dpost ≤ 限值`。

四轮笛卡尔枚举（按“无需超过最深需求 + 转向架差/2 + 一步”剪枝，超 200 万组合保护），
候选按 **总去除量（直径合计）→ 最大单轮切深 → 镟后最小剩余寿命** 排序，保留前 20 条；
界面中列头可改排序。含不稳定轮的候选带“参考”标记。

**无解诊断**：逐约束松弛定位——单轮最小轮径冲突、同轴差冲突、转向架差冲突（高端轮到
dMax 仍追不上低端轮）、轮廓缺测不可用、搜索空间过大——均指出**控制车轮与约束**及定量原因。

### 5. 界面与历史

- 联动：轮位切换、基准带/加工区/缺段影线、目标/实测/镟后预览三型面、Sh/Sd/qR 尺寸标注、
  间隙曲线、十字光标读数、转向架俯视布局（点击切轮、显示实测与镟后径差）。
- 候选行点击即在叠图与布局中预览（目标内移 d 的粉色虚线与镟后直径），再点“采用”入历史。
- 历史为线性撤销/重做（`src/lib/history.ts`，撤销后新采用截断未来分支），随工程状态
  一起持久化到 localStorage，**刷新自动恢复**。
- 明暗双主题。

## ⚠ 模型限制（务必阅读）

本工具是**规划辅助/教学软件，不构成镟修工艺指令**：

1. **目标型面为工程近似**：内置 S1002、LM 仅按关键名义尺寸（Sh/Sd/qR）与踏面锥度用控制点
   标定（S1002 实测回代 Sh≈28.0 / Sd≈32.5 / qR≈10.5；LM 27.0/32.0/7.7），
   **不是经认可的标准样板或机床刀路数据**，不含精确圆弧半径、切点与公差带。生产使用必须
   导入/替换为本路局认可的目标型面数据。
2. **2D 横向轮廓模型**：假设测量截面过轮对中心、踏面与目标同轴可由单一微转角+平移对齐；
   不建模周向不圆（椭圆、多边形、扁疤）、轮对内侧距变化、刀具干涉、机床标定与夹持误差。
3. **“切深”为型面径向内移量**，在滚动圆处换算为直径去除量；凹磨区局部去除可能更大，
   实际刀路需机床补偿。直径换算依赖录入的实测滚动圆直径，录入错误会直接导致错误结论。
4. **缺测绝不插值凑数**：缺段区间不参与约束，dMin 只是下界；噪声过大时给出原始/平滑差值，
   候选标记“参考”。任何致命告警存在时系统拒绝给四轮方案。
5. 限值（最小轮径、同轴/转向架径差、进刀步长）为参数，默认值仅为演示取值，**不代表任何
   规程**；下发前必须由工艺人员核对。
6. 数据仅存于本浏览器 localStorage，不做跨设备同步；清理浏览器数据会丢失。
