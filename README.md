# 轮对镟修余量规划台（Wheelset Allowance Planner）

浏览器端的地铁轮对镟修余量规划演示台：导入四个车轮的横向轮廓点、基准点与滚动圆直径，
先做数据校验与基准刚体对齐，再在加工区间求**只能去料**前提下的最小切深，计算
轮缘高度 Sh、厚度 Sd 与厚度梯度 qR，最后对四轮**离散进给**做联合搜索，
同时满足最小轮径、同轴直径差与转向架直径极差，按总去除量、最大单轮切深、剩余寿命排序。

> ⚠️ **教学/规划演示软件，不是合格的工程镟修计算工具。** 见文末「模型限制」。

## 快速开始

```bash
npm install
npm run dev        # 本地开发
npm test           # 运行全部测试（44 项，含 UI 端到端冒烟）
npm run build      # 类型检查 + 生产构建
```

首屏为空，右侧面板一键载入三个内置示例：

| 示例 | 用途 |
|---|---|
| **正常磨耗** | 四轮踏面凹磨 1.2–2.1 mm，联合搜索给出协调候选，可预览/采用 |
| **偏磨（无解）** | 1 轴右轮缘喉磨耗 5.5 mm，恢复型面即越过最小轮径 → 无解诊断与控制轮 |
| **缺测** | 1 轴右喉弧段缺测 4 mm → 校验拦截、搜索拒绝硬凑 |

## 操作流程

1. **导入/示例**：右侧可粘贴 `x,y` 点列（逗号/制表符/空格分隔，`#` 注释）、
   读取文件，或导入完整 `WheelInput` JSON；选择轮位、填滚动圆直径与基准点。
   同一轮位重复导入会替换旧轮。示例数据的测量系基准为 `(137.5, 412.8)`。
2. **校验**：自动检查点序（x 单调）、重复点、加工区间覆盖、内部缺段（>2.5 mm）、
   方向（轮缘顶点必须在基准负侧）、基准包络与邻点噪声；错误阻止成图与搜索，警告仅提示。
3. **对齐叠图**：纯平移把基准点归零；图中显示实测轮廓、目标型面虚线、公差带、
   过盈区（红色）、控制点 d\*、交叉点（○）、缺测段（斜纹）与 Sh/Sd/qR 标注，
   鼠标悬停给出十字线与逐点过盈量。
4. **候选表**：点击任一行在叠图中预览该方案的镟后型面与去除区（橙色），
   布局图同步显示四轮镟后直径、同轴差与转向架极差（✓/✗）。
5. **采用 / 撤销 / 重做**：采用后形成加工记录；所有操作可撤销重做；
   数据、配置与已采用方案自动保存在浏览器 `localStorage`，刷新后恢复。

## 坐标与尺寸约定

- x：横向，原点为 taping 基准点（距内侧面 70 mm），负方向为轮缘、正方向为踏面外侧；
- y：径向，向上为半径增大方向，镟修切深沿 −y；
- **Sh** = 轮缘顶点 y（相对滚动圆基准线）；
- **Sd** = 顶点下 10 mm 水平线在喉侧的交点到内侧面（x=−70）的距离；
- **qR** = 顶点下 2 mm 与 10 mm 两条水平线喉侧交点间的直线距离。

交点通过分段线性轮廓与水平线的**严格解析求交**得到（`src/geometry/interp.ts`），
喉侧窗口外的交点被剔除；交点缺失时尺寸报无效并说明原因，不返回伪造数值。

## 算法说明

### 单轮最小切深（`src/geometry/cut.ts`）

在加工区间 \[xₘᵢₙ, xₘₐₓ\] 上求

```
d* = max_x ( t(x) − m(x) ),  且 d* ≥ 0
```

使内移后的目标型面 `t(x) − d*` 在每个 x 都不高于实测 `m(x)`（只能去料）。
两轮廓均为 x 单调分段线性，差函数在两轮廓节点的并集上分段线性，最大值必落在节点上，
因此合并节点后取 max 是**精确**的——不使用最近点/法向距离近似。
加工区间未覆盖（端部缺口或内部大间距）时判不可行并列出缺段。

### 四轮耦合离散搜索（`src/geometry/search.ts`）

- 每轮进刀量只能取 `k·步进` 且 `k·步进 ≥ d*ᵢ`（离散进给 + 只能去料）；
- 约束：镟后直径 `Dᵢ − 2kᵢs ≥ 最小轮径`、同轴两轮差、转向架四轮极差；
- DFS 枚举，用同轴配对进给窗口与转向架极差区间可达性剪枝（枚举上限 20 万组，
  超出时标记截断）；叶节点精确校验；
- 排序键：直径削减合计 → 最大单轮切深 → 镟后最小轮径余量；
- **无解诊断**分三类：缺段/校验失败（指出车轮）、最小轮径（给出缺口 mm 数）、
  离散网格（在各轮可达直径格点上解析最小同轴差/转向架极差，指出控制的大轮与小轮）。

### 目标型面（`src/geometry/profiles.ts`）

LM/LMA 为分段三次 Hermite（PCHIP 风格）平滑**近似**，在 0.2 mm 网格上离散。
关键几何接近标准型面的数量级（Sh≈27、Sd≈32、qR 7–9），但**不是厂家标准数据表**。

## 模型限制（务必阅读）

1. **目标型面是几何近似**：内置 LM/LMA 由手工节点 + Hermite 插值生成，
   不代表任何厂家/标准的真实型面坐标，绝对不能用于实际镟修决策；
   实际使用须替换为经认证的型面离散点表。
2. **只做基准平移，不做旋转/最小二乘拟合**：测量坐标系被假定可信，
   基准点是唯一锚点。基准拾取误差会直接平移到 Sh 与切深结果中，
   系统无法识别基准本身的角度偏差。
3. **切深是一维纵向包络**：假定镟修仅改变径向（型面整体内移），
   未建模刀具形状、刀路、让刀、热变形、弹性恢复与轴向串刀；
   也不处理轮缘内侧非加工区与踏面的分区刀路。
4. **轮廓为分段线性**：未做样条平滑/曲率约束，噪声点会直接抬高最小切深
   （因此校验对 >0.12 mm 邻域抖动发警告）；弦差取决于测点间距，
   1 mm 采样在陡轮缘处即可产生约 0.08 mm 的系统性偏置。
5. **直径与横向轮廓解耦**：滚动圆直径由用户手工输入，系统不验证它与轮廓几何的一致性，
   也不考虑多边形、椭圆度、径跳。
6. **限值为教学默认值**（最小轮径 826、同轴 0.5、转向架 2 mm），不针对任何具体车型/规程；
   未建模制动盘、轴颈、同一轮对历史镟修台账等约束。
7. **离散网格 ≠ 真实机床**：搜索假定各轮可独立按统一步进进刀，
   未考虑机床进给分辨率、两次走刀、刀具寿命与装夹误差。
8. 持久化仅在本机浏览器，无并发、无账号、无审计；清除浏览器数据即丢失。

## 技术栈

React 18 + TypeScript（strict）+ Vite 5 + Vitest，纯前端、无后端依赖。
可视化使用原生 SVG（叠图/轮对布局），配色经色盲安全与对比度校验。
